# Справка telecli

Здесь описано, что делать, когда что-то идёт не так, и как настроить
внешний вид программы.

## Настройки

- [Настройки интерфейса](settings.md) — файл `config.toml`: тема, правило
  подсчёта ширины текста, скруглённые края своих сообщений (Nerd Font).

## Когда сообщения не отправляются

- [Отправка приостановлена](sending-paused.md) — программа не может
  открыть очередь и не отправляет сообщения в обход неё. Что делать.
