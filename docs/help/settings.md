# Где лежит файл настроек (Settings file)

Эта страница объясняет, где telecli держит файл настроек, как его
создать, как указать другой и что происходит со старым файлом.

## Где лежит файл

```
~/.config/telecli/config.toml
```

Если в окружении задана переменная `XDG_CONFIG_HOME`, файл лежит в ней:

```
$XDG_CONFIG_HOME/telecli/config.toml
```

Оба пути одинаковы на macOS и на Linux. Если `XDG_CONFIG_HOME` указана
как относительный путь, она игнорируется — так требует спецификация
XDG: относительный путь превращался бы в разные файлы в зависимости от
текущего каталога.

Данные TDLib и очередь отправки лежат в другом месте и сюда не входят:
это `~/.local/share/telecli` (на macOS после `telecli configure` —
`~/Library/Application Support/telecli`). Пути к ним записаны внутри
файла настроек.

## Как создать файл

Самый простой способ — одна команда, которая меняет одну настройку и
не трогает остальные строки:

```
telecli configure set tui.theme gruvbox-dark
```

Если файла нет, он создаётся вместе с нужной секцией. Права: папка
`0700`, файл `0600`.

Если нужно настроить всё сразу (номер приложения Telegram, телефон,
библиотеку TDLib), это делает `telecli configure`.

## Не перезаписывайте файл вручную

Не пишите файл настроек через перенаправление:

```
printf '...' > ~/.config/telecli/config.toml     # так делать не надо
```

Эта команда заменяет файл целиком. Вместе с одной строкой исчезнут и
остальные: папка данных TDLib, папка базы очереди, номер приложения
Telegram и имя профиля входа. Восстанавливать их придётся вручную.

Правьте файл только через `telecli configure set <ключ> <значение>`:
он меняет ровно одну строку и оставляет всё остальное как есть. Если
ключ неизвест или значение ему не подходит (например, написано
`gruvbox`, а тема называется `gruvbox-dark`), команда откажется и файл
не тронет.

Список ключей:

```
telecli configure set
```

## Как посмотреть значение и откуда оно взялось

```
telecli configure get tui.theme
```

Команда печатает значение и говорит, откуда оно: из файла или из
встроенных настроек по умолчанию. Если файла нет, она также печатает
путь, по которому его создать.

`telecli configure status` показывает то же самое целиком: путь к
файлу, откуда он взят (путь по умолчанию, `--config`, `TELECLI_CONFIG`
или старый путь), и что настроено.

## Как указать другой файл

По порядку, показанный порядок и есть приоритет:

1. `--config путь` — для одного запуска;
2. переменная `TELECLI_CONFIG` — для сеанса терминала;
3. `~/.config/telecli/config.toml` (или `$XDG_CONFIG_HOME/...`);
4. встроенные значения по умолчанию, если файла нет.

Путь, указанный первыми двумя способами, должен существовать: если его
нет, telecli скажет об этом, а не продолжит со значениями по умолчанию
(опечатка в пути не должна выглядеть как «всё настроено»).

## Старый файл переезжает сам

До 29.09.2026 на macOS файл лежал в
`~/Library/Application Support/telecli/config.toml`. Теперь он нужен в
`~/.config`.

Если нового файла нет, а старый есть, telecli при первом запуске
переносит его сам:

1. копирует файл в `~/.config/telecli/config.toml` (папка `0700`, файл
   `0600`);
2. читает копию и сверяет её со старым файлом — все значения должны
   совпасть;
3. только после этого переименовывает старый файл в
   `config.toml.moved-<дата>` рядом с ним. Старый файл не удаляется.

Перенос не молчаливый: одна строка в выводе говорит, что и куда
перенесено.

Если на любом шаге что-то пошло не так, старый файл остаётся на месте
и не меняется, telecli работает с ним, а строка в выводе говорит, что
перенос не удался и почему. Следующий запуск попробует снова.

### Файл в обоих местах

Если файлы лежат в обоих местах, telecli не запустится и напишет оба
пути: решить, какой из двух оставить, может только человек. Оставьте
тот, в котором ваши настройки, и удалите второй.

### Настройка, которой нет в сборке

Если в секции `[tui]` есть строка, которой эта сборка не знает (например
`nerd_font`, добавленный вами раньше), telecli напечатает предупреждение
с её названием и продолжит работу. В остальных секциях неизвестный ключ —
ошибка: там это опечатка в существующей настройке.

## Как удалить файл и вход

```
telecli configure reset
```

Команда сначала перечисляет, что удалит: файл настроек по пути и профиль
входа в Telegram по имени. Для удаления нужно набрать слово `delete`
целиком; `y` не подходит. Если запускаете без терминала (скрипт, CI),
есть флаг `--yes`.

Очередь отправки и её ключ остаются на месте: без ключа уже отправленные
сообщения не прочитать.

Если нужна только одна настройка, разбирать файл не нужно:

```
telecli configure set log_level debug
telecli configure set data_dir "$HOME/telecli-data"
```

## Ключи, которые можно менять

| Ключ | Что это |
| --- | --- |
| `log_level` | уровень журнала, `info` по умолчанию |
| `data_dir` | папка с данными TDLib (абсолютный путь) |
| `tdlib.library_path` | путь к библиотеке TDLib (абсолютный) |
| `tdlib.database_dir` | папка базы данных TDLib (абсолютный) |
| `tdlib.files_dir` | папка файлов TDLib (абсолютный) |
| `tdlib.receive_timeout_ms` | сколько ждать ответа TDLib, мс |
| `tdlib.shutdown_timeout_ms` | сколько ждать закрытия TDLib, мс |
| `auth.api_id` | номер приложения с my.telegram.org |
| `auth.credential_profile` | имя профиля входа в связке ключей |
| `message_delivery.mode` | `durable` — единственный поддерживаемый режим |
| `message_delivery.data_dir` | папка очереди (абсолютный путь) |
| `message_delivery.database_id` | имя очереди в папке очереди |
| `message_delivery.instance_id` | имя экземпляра очереди |
| `tui.theme` | тема: `catppuccin-mocha`, `gruvbox-dark`, `tokyo-night-storm` |
| `tui.color` | цвет: `auto`, `always` или `never` |
| `tui.width` | ширина: `auto`, `grapheme` или `codepoint` |

Секреты — API hash и телефон — в файле настроек не лежат никогда: они
в системном хранилище (Keychain на macOS), а в файле только имя профиля.
Поэтому пароль и код подтверждения через `configure set` не задаются.
