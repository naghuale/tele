# Настройки интерфейса (Interface settings)

telecli настраивается одним файлом — `config.toml`. Всё, что в нём можно
менять, описано здесь простыми словами: что настройка делает, какое значение
у неё по умолчанию и как выглядит строка в файле.

## Где лежит файл

По умолчанию:

```
~/Library/Application Support/telecli/config.toml
```

(на macOS; на Linux — `~/.config/telecli/config.toml`)

Другой файл можно указать один раз:

- флагом `--config /путь/к/config.toml` у любой команды;
- переменной окружения `TELECLI_CONFIG=/путь/к/config.toml`.

Путь покажет и `telecli doctor`:

```
telecli doctor
```

Файл создаётся сам при первом запуске `telecli configure`.

## Секция `[tui]`

Секция `[tui]` — это внешний вид программы. В ней три настройки, и все
три необязательные: если строки нет, работает значение по умолчанию.

```toml
[tui]
theme = "catppuccin-mocha"
width = "auto"
nerd_font = false
```

### `theme` — цветовая тема

Что делает: выбирает, какими цветами нарисована программа.

Значение по умолчанию: `catppuccin-mocha`.

Возможные значения:

- `catppuccin-mocha` — тёмная, фиолетово-розовые акценты;
- `gruvbox-dark` — тёмная, тёплая, жёлтый акцент;
- `tokyo-night-storm` — тёмная, холодная, синий акцент.

Если написать другое имя, telecli скажет, какие имена есть, и не запустится
с неправильным экраном.

### `width` — как считать ширину текста

Что делает: говорит программе, как терминал считает ширину символов.
Это нужно для эмодзи, флагов и других знаков, которые терминалы считают
по-разному.

Значение по умолчанию: `auto` — при запуске telecli сам спрашивает терминал
и считает так же, как терминал.

Возможные значения:

- `auto` — спросить терминал (по умолчанию);
- `grapheme` — считать по правилам Unicode для эмодзи;
- `codepoint` — считать по правилу `wcwidth` (так считает «Терминал» на
  macOS и iTerm2).

Меняйте, только если с текстом заметно ломается вёрстка: символы наезжают
друг на друга или строка переносится не там. `telecli doctor` показывает,
какое правило действует сейчас.

### `nerd_font` — скруглённые края своих сообщений

Что делает: включает полукруглые края у сообщений, которые отправили вы.
Края рисуются двумя символами из Nerd Font — обычный шрифт их не содержит.

Значение по умолчанию: `false` — края прямые. Это значение по умолчанию
выбрано потому, что Nerd Font есть не у всех: терминал без него
нарисует вместо скруглений пустые квадраты, и сообщение будет выглядеть
хуже, чем с прямыми углами.

Как включить:

```toml
[tui]
nerd_font = true
```

Что увидите: у ваших сообщений по краям блока появятся полукруглые
скругления. Без этой строки — прямые углы, ничего лишнего.

Проверить, что настройка дошла до программы:

```
telecli doctor
```

```
Interface font: Nerd Font
```

Если написано `Interface font: plain` — настройка выключена.

#### Как поставить Nerd Font в «Терминале» на macOS

1. Скачайте любой Nerd Font (например, JetBrainsMono Nerd Font или
   MesloLGS NF) со страницы проекта:
   <https://www.nerdfonts.com/font-downloads>
2. Установите его: скачанный файл `.zip` распакуйте, двойным щелчком по
   файлу шрифта нажмите «Установить шрифт» и подтвердите.
3. Выберите его в «Терминале»: меню **Терминал → Настройки → Профили →
   Текст → Шрифт → Изменить…** (в старых версиях — «Выбрать…»), найдите
   шрифт с «Nerd Font» или «NF» в названии и нажмите «ОК».
4. Добавьте в `config.toml` строку `nerd_font = true` и перезапустите
   telecli.
5. Проверьте: у ваших сообщений должны появиться скруглённые края. Если
   вместо них — пустые квадраты, значит в терминале выбран не тот шрифт;
   вернитесь к шагу 3.

В iTerm2 то же самое: **Настройки → Профили → Текст → Шрифт**, там же
в поле «Use Nerd Font Glyphs» можно поставить галочку, если она есть.

## Другие настройки файла

Остальные секции (`[tdlib]`, `[auth]`, `[message_delivery]`, `log_level`,
`data_dir`) telecli настраивает сам при первом запуске. Правьте их руками
тогда, когда нужен конкретный путь к папке данных, конкретный профиль
TDLib или конкретный способ доставки сообщений.

Про отправку приостановлена — в [sending-paused.md](sending-paused.md).
