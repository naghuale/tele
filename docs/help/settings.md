# Настройки интерфейса (Interface settings)

telecli настраивается одним файлом — `config.toml`. Всё, что в нём можно
менять, описано здесь простыми словами: что настройка делает, какое значение
у неё по умолчанию и как выглядит строка в файле.

## Где лежит файл

По умолчанию:

```
~/Library/Application Support/telecli/config.toml
```

(на macOS; на Linux — `~/.config/telecli/config.toml`)

Другой файл можно указать один раз:

- флагом `--config /путь/к/config.toml` у любой команды;
- переменной окружения `TELECLI_CONFIG=/путь/к/config.toml`.

Путь покажет и `telecli doctor`:

```
telecli doctor
```

Файл создаётся сам при первом запуске `telecli configure`.

## Секция `[tui]`

Секция `[tui]` — это внешний вид программы. В ней шесть настроек, и все
шесть необязательные: если строки нет, работает значение по умолчанию.

```toml
[tui]
theme = "catppuccin-mocha"
width = "auto"
clock = "auto"
nerd_font = false
unread_counter = "chats"
```

### `theme` — цветовая тема

Что делает: выбирает, какими цветами нарисована программа.

Значение по умолчанию: `catppuccin-mocha`.

Возможные значения:

- `catppuccin-mocha` — тёмная, фиолетово-розовые акценты;
- `gruvbox-dark` — тёмная, тёплая, жёлтый акцент;
- `tokyo-night-storm` — тёмная, холодная, синий акцент.

Если написать другое имя, telecli скажет, какие имена есть, и не запустится
с неправильным экраном.

### `width` — как считать ширину текста

Что делает: говорит программе, как терминал считает ширину символов.
Это нужно для эмодзи, флагов и других знаков, которые терминалы считают
по-разному.

Значение по умолчанию: `auto` — при запуске telecli сам спрашивает терминал
и считает так же, как терминал. Если спросить не удалось, программа считает
по правилу `grapheme`: строка, посчитанная уже, чем её рисует терминал,
доходит до последнего столбца окна, терминал переносит её на следующую строку
и всё под ней сдвигается. Поэтому `codepoint` стоит ставить только там, где
терминал заведомо считает именно так.

Возможные значения:

- `auto` — спросить терминал, а если он не ответил, считать по `grapheme`
  (по умолчанию);
- `grapheme` — считать по правилам Unicode для эмодзи;
- `codepoint` — считать по правилу `wcwidth` (так считает «Терминал» на
  macOS и iTerm2).

Ширина эмодзи от правила не зависит: кластер с эмодзи-рисунком, флаг и
последовательность со значащим селектором или с ZWJ занимают две колонки в
обоих правилах, потому что терминал рисует такой глиф в две ячейки. Поэтому
`width` влияет на остальные символы — иероглифы, комбинирующие знаки, —
а не на эмодзи.

Меняйте, только если с текстом заметно ломается вёрстка: символы наезжают
друг на друга или строка переносится не там. `telecli doctor` показывает,
какое правило действует сейчас.

### `clock` — как записан час

Что делает: говорит, как telecli пишет время — `20:06` или `08:06 PM`.

Значение по умолчанию: `auto` — программа спрашивает систему при запуске.
На macOS это «Системные настройки → Основные → Язык и регион» →
«24-часовой формат»: если галочка стоит, время идёт как `20:06`, если нет —
как `08:06 PM`. На Linux это `LC_TIME` локали: если в её формате есть
`AM`/`PM`, время двенадцатичасовое, иначе двадцатичетырёхчасовое. Если
спросить не удалось (машина без настроек, локаль не установлена) —
`20:06`, и telecli об этом не сообщает: это просто часы.

Возможные значения:

- `auto` — спросить систему (по умолчанию);
- `12h` — всегда `08:06 PM`;
- `24h` — всегда `20:06`.

`12h` и `24h` важнее системы: если написано `12h`, будет `08:06 PM`, даже
если macOS настроена на 24 часа. Настройка существует ровно для этого
случая — когда система отвечает не то, чего хочется.

Время в ленте, в списке чатов, в строке «last seen» и в повторах отправки
пишется одним и тем же способом. Если в `08:06 PM` не узнаётся привычное
время, поставьте `24h`.

Разделители дней в ленте и в списке чатов от часа не зависят: `Today`,
`Yesterday`, день недели или дата — это про дату, а не про формат.

Проверить:

```
telecli doctor
```

```
Interface clock: auto (system)
  auto: the setting of the machine is read when the TUI starts
```

Если написано `Interface clock: 12h (configured)` — в файле стоит `12h`.
Если написано `(configured)` для `24h` — то же про `24h`.

### `nerd_font` — скруглённые края

Что делает: включает полукруглые края там, где форма блока их выдерживает:
у однострочного блока сообщения и у счётчика непрочитанного в списке чатов.
Края рисуются двумя символами из Nerd Font — обычный шрифт их не содержит.

Значение по умолчанию: `false` — края прямые. Это значение по умолчанию
выбрано потому, что Nerd Font есть не у всех: терминал без него
нарисует вместо скруглений пустые квадраты, и сообщение будет выглядеть
хуже, чем с прямыми углами.

#### Как включить

`nerd_font` — это строка в файле `config.toml` (путь — в разделе
«Где лежит файл»). Если файла ещё нет, создайте его такой одной командой:

```sh
mkdir -p ~/Library/Application\ Support/telecli; f=~/Library/Application\ Support/telecli/config.toml; [ -e "$f" ] || printf '[tui]\nnerd_font = true\n' > "$f"
```

(на Linux — `~/.config/telecli/config.toml` вместо пути выше.)

Если файл уже есть, добавьте в него две строки — в секцию `[tui]` или,
если её ещё нет, в конец файла:

```toml
[tui]
nerd_font = true
```

#### Как это выглядит

Сообщение из нескольких строк — прямоугольник в любом случае: края у него
прямые, и скруглять их нечем. Внутри блока — воздух со всех четырёх
сторон: колонка слева и справа и пустая строка сверху и снизу, на фоне
самого блока. Без настройки:

```text
░░░░░░░░░░░░░░░░░░░░░░░░
  ░░ Anna Example  14:28
  ░░ Привет, как дела?
░░░░░░░░░░░░░░░░░░░░░░░░

                       ░░░░░░░░░░░░░░░░░░░░░░░░
                       ░░ Проверяю новую сборку.
                       ░░              ✓ sent 14:30
                       ░░░░░░░░░░░░░░░░░░░░░░░░
```

Имя отправителя и время — одной строкой, через два пробела, время приглушённым.
Пустая строка между сообщениями — это фон ленты, а не блока: у сообщения
сверху и снизу воздух внутри блока, и между двумя сообщениями — одна строка
пустоты.

С настройкой — тот же экран, без единой правки: у блока длиннее одной
строки края прямые, потому что полукруглый край высотой в одну строку на
двух строках даёт две пилюли одна над другой.

Однострочное сообщение — на экранах короче двадцати строк, где у сообщения
остаётся только текст, — вот где настройка видна:

```text
  ⸲ ok ⸲                             ⸲ ok ⸲
```

Счётчик непрочитанного в списке чатов при настройке становится пилюлей с
полукруглыми краями, а без неё — прямоугольником. Он всегда стоит на
правом краю второй строки чата, на одной вертикали со временем в первой,
как бы длинным ни было превью:

```text
nerd_font = true              nerd_font = false
  Anna Example    14:28        Anna Example    14:28  
  Привет!          ⸲ 2 ⸲        Привет!          ░ 2 ░  
```

`░` — клетка фона блока, `⸲` — край в цвете самого блока.

Свои сообщения и так отличаются от чужих: у ваших блок в цвете темы
(подмешанный к основному серому), у чужих — в обычном сером. Настройка
`nerd_font` добавляет к этому форму углов, а не цвет.

Проверить, что настройка дошла до программы:

```
telecli doctor
```

```
Interface font: Nerd Font
```

Если написано `Interface font: plain` — настройка выключена.

#### Как поставить Nerd Font в «Терминале» на macOS

1. Скачайте любой Nerd Font (например, JetBrainsMono Nerd Font или
   MesloLGS NF) со страницы проекта:
   <https://www.nerdfonts.com/font-downloads>
2. Установите его: скачанный файл `.zip` распакуйте, двойным щелчком по
   файлу шрифта нажмите «Установить шрифт» и подтвердите.
3. Выберите его в «Терминале»: меню **Терминал → Настройки → Профили →
   Текст → Шрифт → Изменить…** (в старых версиях — «Выбрать…»), найдите
   шрифт с «Nerd Font» или «NF» в названии и нажмите «ОК».
4. Добавьте в `config.toml` строку `nerd_font = true` (см. «Как включить»
   выше) и перезапустите telecli.
5. Проверьте: у однострочных сообщений и у счётчиков непрочитанных должны
   появиться скруглённые края. Если вместо них — пустые квадраты, значит в
   терминале выбран не тот шрифт; вернитесь к шагу 3.

В iTerm2 то же самое: **Настройки → Профили → Текст → Шрифт**, там же
в поле «Use Nerd Font Glyphs» можно поставить галочку, если она есть.

Значок закреплённого чата 📌 в списке к этой настройке отношения не имеет:
это обычный эмодзи, а не значок из Nerd Font, и он рисуется всегда — включать
`nerd_font` ради него не нужно. Подробнее — в
[Списке чатов](chat-list.md).

### `unread_counter` — что считает число в заголовке списка чатов

Что делает: выбирает, что означает число в заголовке списка чатов.

Значение по умолчанию: `chats`.

Возможные значения:

- `chats` — сколько **чатов** имеют непрочитанные сообщения; заглушённые
  чаты не входят, как и в Telegram (по умолчанию);
- `messages` — сумма непрочитанных сообщений по всем чатам списка,
  включая заглушённые. Это то, что стояло в заголовке раньше, и сумма
  здесь большая: один канал с тысячей сообщений определяет её целиком,
  пока кружки у строк показывают маленькие числа;
- `off` — числа в заголовке нет совсем. Кружок у каждого чата с его
  собственным счётчиком остаётся.

Ничего из этого не меняет кружки у чатов: там по-прежнему число
**сообщений** в этом чате.

Если написать другое слово, telecli скажет, какие есть, и не запустится с
неправильным экраном.

Проверить, какая настройка действует:

```
telecli doctor
```

```
Interface unread counter: chats
  chats: the chats with something unread, silenced chats left out
```

Проверить руками: прочитайте чат на телефоне и посмотрите на заголовок
списка — число уменьшилось, перезапускать telecli не нужно.

Подробнее о самом списке — в [Списке чатов](chat-list.md).

## Другие настройки файла

Остальные секции (`[tdlib]`, `[auth]`, `[message_delivery]`, `log_level`,
`data_dir`) telecli настраивает сам при первом запуске. Правьте их руками
тогда, когда нужен конкретный путь к папке данных, конкретный профиль
TDLib или конкретный способ доставки сообщений.

Про отправку приостановлена — в [sending-paused.md](sending-paused.md).
